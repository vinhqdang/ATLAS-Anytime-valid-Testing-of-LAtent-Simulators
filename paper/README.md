# ATLAS manuscript

TMLR format (`tmlr.sty`, `tmlr.bst`). Anonymous by default; for a camera-ready version use
`\usepackage[accepted]{tmlr}` and add the author block.

- `main.tex` and `sec_*.tex` -- manuscript sources.
- `tab_real.tex` -- generated by `python3 make_tables.py` from `../results/exp8_*.json`.
- `references.bib`, `figures/` -- bibliography and figures.

Build: `pdflatex main && bibtex main && pdflatex main && pdflatex main`.
